# Updating Your Avatar

Got a new version of your avatar? Whether the creator pushed an update or you just want to apply changes, here's how to get it into VRChat.

---

## Step 1: Import the new unitypackage

Download the updated avatar package from the creator, then import it into your Unity project by double-clicking the `.unitypackage` file (or dragging it into the Project window). Unity will ask which files to import — in most cases you can import everything.

This overwrites the old avatar files in your project with the new ones.

---

## Step 2: Upload it

Once the import is done, upload the avatar the same way you did the first time. Head over to the [Uploading](./upload/uploading) page if you need a refresher on the steps.

:::tip
You don't need to re-enter the name or description. VRChat remembers those from your first upload since you're updating the same avatar, not creating a new one.
:::

:::info
Uploading overwrites the existing version of your avatar — no duplicates, it just updates the same one in your list.
:::

---

## Don't forget the Quest version!

If your avatar has a Quest version, make sure you upload that too — otherwise Quest users (including yourself on Quest) will still see the old version. Once you've uploaded for Windows, repeat the process and click **Build & Publish for Android** instead.

The Quest and PC versions are already linked from your first upload, so you don't need to redo that part.
