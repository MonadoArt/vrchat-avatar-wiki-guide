# Substance Painter

Adobe Substance Painter lets you paint textures directly onto the 3D model, which makes it much easier to paint across seams and see exactly how your work looks on the avatar. It's the more capable option compared to flat 2D editing, but has a steeper learning curve.

For a quick start, check out this [introduction video](https://youtu.be/d9hHn1Dk0us?t=85) and this [beginner playlist](https://youtube.com/playlist?list=PLZpDYt0cyiusjyoZla7ZDCG69SvP0MeMr&si=VPYcZdiaGjOEVeb8).
