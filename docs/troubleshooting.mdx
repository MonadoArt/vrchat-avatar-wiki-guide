# Common Errors

A reference for errors you're likely to run into when uploading or using avatars.

---

## SDK / Upload errors

### "No avatar descriptor found"
<SubsectionBanner />

**Cause:** The selected object doesn't have a `VRC Avatar Descriptor` component, meaning you likely dragged the raw .fbx model instead of the prefab into your hierarchy!

**Fix:** Make sure you put the Prefab into your hierarchy (check [Importing the Avatar](./upload/importing#step-4---find-the-scene-and-prefab))

---

### "Build failed" with no clear reason
<SubsectionBanner />

**Cause:** You might have some dependencies missing or you are on the wrong version of Unity.

**Fix:**
1. Check the Unity **Console** (Window → General → Console) for any red errors.
2. Fix all script errors before trying to upload.
3. If errors are in third-party packages, try reimporting them via the Creator Companion.

---

### "VRCFury encountered an error."
<SubsectionBanner />

If you get the "VRCFury encountered an error. Failed to build VRCFury component: " error while entering play mode or attempting to upload the model that means you are missing either **GoGoLoco** or **ADJerry's Facetracking Templates** while using an older version of the Avatar. <br />

**Fix: Do one of the following**
<ol style={{ listStyleType: 'upper-alpha' }}>
    <li>
        Update the Lucario Avatar (Check [Updating](./updating.mdx))
    </li>
    <li>
        Remove either "FT- Lucario ReUnited UE FaceTracking Prefab" or "GogoLoco Beyond - Lucario ReUnited  (VRCFury)" from the avatar in the Hierarchy. <br />
        (use the images below to figure out which one to delete)
    </li>
</ol>

## Unity errors


### Avatar shows as bright neon pink
<SubsectionBanner />
If your avatar appears as neon pink you most likely are missing the Poiyomi Shaders!

**Cause:** Likely missing shaders

**Fix:**
1. Install Poiyomi using the [Installing needed things](./upload/installation#step-4---add-the-package-sources-to-vcc) guide
2. If the shaders still appear as pink even after importing Poiyomi you might need to re-assign the shader as seen in the video below!

## Quest-specific issues

### Quest avatar shows as a different avatar than PC
<SubsectionBanner />

**Cause:** The Quest and PC versions have different Pipeline IDs and aren't linked.

**Fix:** See the [Quest version linking steps](upload/uploading#5-upload-mobile-version) in the Uploading guide.
