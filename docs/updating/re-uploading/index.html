Re-uploading

If you've changed something on your avatar - or updated your packages - you'll need to re-upload for those changes to actually show up in VRChat. It's basically the same process as the first upload.

info

Re-uploading overwrites the existing version of your avatar. No duplicates - it just updates the same one in your list.

When do you need to re-upload?​

Any time you've changed something in Unity that you want to see in VRChat. For example:

  • You updated a package (like GoGoLoco or VRCFury)
  • You swapped out a texture or material
  • You adjusted a setting on the avatar
  • You made any other edit inside the Unity project

Just updating packages in VCC is not enough on its own - you always need to re-upload after.

How to re-upload​

  1. Open your project in Unity through the Creator Companion.
  2. Make sure your avatar is in the scene. If it isn't, find it in the Project window and drag it into the Hierarchy.
  3. Click VRChat SDK in the top menu bar, then Show Control Panel.
  4. Go to the Builder tab and confirm your avatar is selected in the dropdown.
  5. Check for any red errors - fix those before continuing.
  6. Click Build & Publish for Windows.
  7. Wait for Unity to finish building. This can take a few minutes.

Done - your avatar in VRChat will now reflect the changes.

tip

You don't need to re-enter the name or description. VRChat remembers those from the first upload since you're updating, not creating a new one.

Re-uploading the Quest version​

If your avatar has a Quest version, you'll need to re-upload that separately too. Once you've done the steps above, repeat them and click Build & Publish for Android instead of Windows.

The Quest and PC versions are linked by their shared ID so you don't need to go through the ID-linking process again - that only has to be done once on first upload.
