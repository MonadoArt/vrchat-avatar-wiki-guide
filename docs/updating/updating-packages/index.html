Updating Packages

The packages you installed (VRCFury, GoGoLoco, Poiyomi Toon, and ADJerry's Face Tracking) get updated by their developers over time with bug fixes and new features. This page explains how to update them.

info

You do not need to update packages every time you upload. Only update if something is broken, if a guide tells you to, or if you want new features.

How to update via the Creator Companion​

Updating packages is done through the same Creator Companion you used to install them.

  1. Open the Creator Companion.
  2. Click Projects in the sidebar.
  3. Find your project and click Manage Project.
  4. Any packages that have an available update will show an up arrow or a newer version number next to them.
  5. Click the version dropdown next to the package and select the latest version, then confirm.
  6. Repeat for any other packages that need updating.
tip

Update one package at a time and open Unity in between to make sure nothing breaks. Updating everything at once can make it harder to figure out what caused a problem if something goes wrong.

Checking what version you have​

In the Manage Project page, each installed package shows its current version number next to the name. You can compare this against the version listed on the package's website or repository page if you're unsure whether you're up to date.

After updating​

Once you've updated packages in VCC, close and reopen your Unity project. Unity will pick up the changes automatically. Check the Console for any red errors before trying to re-upload.

If something breaks after an update, check the Troubleshooting page or the support channels for the specific package that was updated.
