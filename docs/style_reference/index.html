Style Reference

Visual reference and usage guide for every component and style used across this wiki.

Headings & Ribbons​

The ## above is what every ## heading looks like automatically — no import needed. The XenoMarkers components give explicit control over the same shapes.

SectionTab
SectionBanner

SubSectionBanner
### Subsection Name
<SubSectionBanner />
GaugeHeaderright value

Usage​

Most of the time ## headings are all you need. Use the explicit components when you need a tab label above a banner, a named sub-section break, or a gauge bar with a right-side value:

import { SectionTab, SectionBanner, SubSectionBanner, GaugeHeader } from '@site/src/components/XenoMarkers';

<SectionTab>Optional</SectionTab>
<SectionBanner>My Section</SectionBanner>

### Named Break
<SubSectionBanner />

<GaugeHeader value="3/3">Progress Header</GaugeHeader>

Sizing​

Every component accepts a size prop that sets its font-size. All internal dimensions use em units so everything scales proportionally:

<SectionBanner size="0.8rem">Smaller than default</SectionBanner>
<SectionBanner size="1.5rem">Bigger than default</SectionBanner>
<GaugeHeader size="1rem" value="done">Larger gauge</GaugeHeader>

Default sizes: SectionTab → 0.72rem, SectionBanner → 1rem, SubSectionBanner → 1.25rem, GaugeHeader → 0.78rem.

ToC Behavior​

The table of contents only picks up markdown ## headings — JSX components are invisible to it. If a section using an explicit component also needs a ToC entry, place a ## heading immediately before it:

## My Section

<SectionBanner>My Section</SectionBanner>

The CSS collapses the ## heading visually (the component shows instead) while keeping the anchor alive for the ToC link.

Cards​

All card components share a dark frame with metallic-yellow rivets at each corner.

LocationCard​

Settings

Shows a screenshot inside the card frame with an optional floating pill label above it. src is passed through useBaseUrl automatically — use the /img/ path as-is.

import { LocationCard } from '@site/src/components/LocationCard';

<LocationCard src="/img/settings-panel.png" title="Settings" />
<LocationCard src="/img/something.png" />  {/* no label */}

The highlight prop annotates regions of the screenshot. Coordinates are fractions of the image (0–1). Highlighted regions pulse with a gold border; hovering fades them so the full image is visible. grow expands a region outward by that many pixels on every side:

<LocationCard
  src="/img/panel.png"
  title="Panel"
  highlight={[
    { l: 0.05, t: 0.1, w: 0.4, h: 0.15, text: "Name field" },
    { l: 0.6,  t: 0.7, w: 0.3, h: 0.2,  text: "Save button", grow: 4 },
  ]}
/>

PlaceholderCard​

⚠️Put a screenshot of the right-click menu here
Right-click Menu

Same frame and rivets as LocationCard, but shows a caution area instead of an image. Use it anywhere a screenshot is still needed and replace the whole tag with a <LocationCard> once the real image is ready.

import { PlaceholderCard } from '@site/src/components/PlaceholderCard';

<PlaceholderCard title="Settings Panel" text="Put a screenshot of the Settings panel here" />

XenoCardFrame​

Anything here gets the riveted frame.

Custom Content

The raw frame primitive used by LocationCard and PlaceholderCard. Use it directly when you need the riveted frame around non-image content. Accepts title, style, className, frameClassName, labelClassName, frameStyle, labelStyle, and topSpacing="none" to suppress the margin reserved for the floating label.

import { XenoCardFrame } from '@site/src/components/XenoCardFrame';

<XenoCardFrame title="Custom Content">
  <p style={{ padding: '1rem', color: 'white' }}>Anything here gets the riveted frame.</p>
</XenoCardFrame>

Layout​

DocsPageLead​

Centers a short intro sentence directly under the page h1. Collapses its own bottom margin so it sits tight against whatever follows.

import { DocsPageLead } from '@site/src/components/DocsPageLead';

# My Page

<DocsPageLead>A one-liner that describes what this page is for.</DocsPageLead>

## First Section

DocsMediaRow​

Two-column layout: text on the left, a media card on the right. Stacks vertically on narrow viewports with the media below. The media prop takes any JSX, typically a <LocationCard /> or <HoverVideo />.

import { DocsMediaRow } from '@site/src/components/DocsMediaRow';

<DocsMediaRow media={<LocationCard src="/img/something.png" title="The Panel" />}>

Your step-by-step instructions here. The media card floats right at 220 px wide
and aligns to the bottom of the text column.

</DocsMediaRow>

HoverOption & HoverVideo​

Hover-aware wrapper for optional steps that have an accompanying video. Hovering the <HoverOption> block adds a warm left accent bar and plays the embedded <HoverVideo>. Omit src from <HoverVideo> to show a "Video coming soon" placeholder instead.

import { HoverOption, HoverVideo } from '@site/src/components/HoverOption';

<HoverOption>
  <DocsMediaRow media={<HoverVideo src="/video/my-option.mp4" title="Right-click Menu" />}>

  1. Your steps here...

  </DocsMediaRow>
</HoverOption>

The hover effect degrades gracefully to plain content if JS is unavailable.

Inline Icons​

VCC Interface Elements​

These render inline replicas of VCC's own UI so prose instructions match what the reader sees. Import what you need:

import {
  VccIcon, VccProjectsLabel, VccManageProjectLabel,
  AddIcon, RemoveIcon, VersionNone, VersionInstalled,
} from '@site/src/components/InstallationInlineUi/InstallationInlineUi';

<VccIcon /> — the VCC favicon inline with text. Accepts a size prop (CSS value, default 1.2em).

Open Creator Companion.

Open <VccIcon /> **Creator Companion**.

<VccProjectsLabel /> — the Projects sidebar entry as it appears in VCC, including the grid icon.

Go to the Projects tab.

Go to the <VccProjectsLabel /> tab.

<VccManageProjectLabel /> — the Manage Project action label, styled like a small VCC button.

Click Manage Project next to your project.

Click <VccManageProjectLabel /> next to your project.

<AddIcon /> and <RemoveIcon /> — the circular add and remove buttons from VCC's package list.

Click to install, to remove.

Click <AddIcon /> to install, <RemoveIcon /> to remove.

<VersionNone /> and <VersionInstalled /> — the version dropdown pills from the VCC package list.

If the version column shows none, the package isn't installed. Once installed it shows 1.2.3.

If the version column shows <VersionNone />, the package isn't installed. Once installed it shows <VersionInstalled />.

Small inline icons matching the Unity editor's own file-type indicators. Use them next to any mention of a Unity asset type.

import { SceneIcon, PrefabIcon, ModelIcon, PrefabModelIcon, PrefabVariantIcon, UnityPackageIcon, UnityPackage } from '@site/src/components/UnityIcon';
<SceneIcon />
<PrefabIcon />
<ModelIcon />
<PrefabModelIcon />
<PrefabVariantIcon />
<UnityPackageIcon />
Save your .unitypackage file somewhere you can find it.

All icon components accept an optional size prop (number, pixels). Default is 16.

Double-click the scene file <SceneIcon /> to open it.
Drag the prefab <PrefabIcon /> into the Hierarchy.

<UnityPackage /> combines the .unitypackage filename and icon into a single styled inline badge. Use it instead of writing `.unitypackage` <UnityPackageIcon />.

Page Setup​

File Structure​

Every page is .mdx (not .md) so React components work inline. Frontmatter sets the sidebar position and title:

---
sidebar_position: 2
title: My Page
---

Imports go right after the frontmatter block, before any content.

Images & Assets​

Static images go in static/img/. In markdown prose, use the path as-is:

![alt text](/img/something.png)

Inside a React component or JSX, always use useBaseUrl or the path will break in production:

import useBaseUrl from '@docusaurus/useBaseUrl';
const src = useBaseUrl('/img/something.png');

Admonitions​

Callout boxes for things that need to stand out. Keep them short — one or two sentences max.

note

note — neutral extra context that's helpful but not critical. Tag: :::note

tip

tip — shortcuts, recommendations, or things that make life easier. Tag: :::tip

info

info — background context the reader might not know. Tag: :::info

caution

caution — things that are easy to get wrong or miss. Also used as a placeholder marker for screenshots still needed. Tag: :::caution

warning

warning — things that can actually break something if ignored. Tag: :::warning

danger

danger — use sparingly, only for things with serious consequences. Tag: :::danger

CSS Architecture​

The site CSS is split into six files loaded in dependency order from src/css/custom.css:

theme-foundation.css — all --xeno-* CSS custom properties, base html/body rules, scrollbar styling, and text-wrap settings. This is the only place hex values should ever appear.

theme-decor.css — the four fixed pseudo-element layers that create the framed decorative border on every page. Appearance is driven entirely by CSS variables, so per-page themes only need to override those variables.

theme-docs.css — main content column: doc container background, h1/h2 heading styles, and the rules that hide placeholder markdown headings when a XenoMarkers component immediately follows them.

theme-sidebar.css — sidebar shell, category frame cards with rivets, pill labels, the hover-highlight cursor, and the no-frame category modifier.

theme-toc.css — right-hand table of contents panel, active cursor indicator, and the previous/next pagination cards.

theme-chrome.css — breadcrumbs, navbar, footer (including the rivet decorations at the footer corners), and kbd/abbr overrides.

Page Themes​

Each section of the wiki has its own color theme that changes the decorative border layers. Themes are defined in src/theme/shared/xenoPageTheme.ts and applied automatically on navigation — no MDX changes required.

Path patterndata-xeno-decorDecor styleNotes
/docs/troubleshootingtroubleshootingaltYellow/olive palette, alternate mask images
/docs/updatingupdatingdefaultBlue/purple palette
/docs/customizing/**customizingdefaultDefault palette
/docs/upload/**uploaddefaultDefault palette
Everything elsedefaultdefaultDefault warm orange/brown palette

To add a new theme, add an entry to PAGE_THEME_DEFINITIONS in xenoPageTheme.ts:

{
  pattern: /\/docs\/my-section(?:\/|$)/,
  decor: 'my-section',
  style: 'default',   // 'default' or 'alt' — switches the mask image set
  variables: {
    '--xeno-page-bg-bottom': '#5ab2f2',
    '--xeno-page-decor-before-ramp-base': '#113357',
    '--xeno-page-decor-after-tl': 'rgb(197 220 237)',
    // ...
  },
},

style: 'alt' swaps in decor_top_alt.png, decor_bottom_alt.png, and decor_middle_alt.png. Use it if the default mask shapes don't suit the palette.
