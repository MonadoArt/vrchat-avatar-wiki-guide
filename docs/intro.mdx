# Avatar Wiki

Welcome to the Avatar Wiki - your guide to getting your avatar set up and into VRChat.

Use the sidebar to get to wherever you need to go.

## What's in this wiki

- **[Upload](./upload/installation)** - How to install your tools and get your avatar into VRChat.
- **[Troubleshooting](./troubleshooting/common-errors)** - Common errors and how to fix them.

## Before you start

Make sure you have:

- A VRChat account (with [trust rank](https://docs.vrchat.com/docs/vrchat-safety-and-trust-system) that allows avatar uploads)
- A compatible avatar project (Unity)
- The [VRChat Creator Companion](https://vcc.docs.vrchat.com/) installed

:::tip
New to this? Start with the [Installation](./upload/installation) page.
:::
