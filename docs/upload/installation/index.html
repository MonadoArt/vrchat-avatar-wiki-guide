Installation

To get an avatar into VRChat, you'll need to install a few things first. This page walks you through all of it step by step - no prior experience needed.​

Step 0 - VRChat Trust Rank Requirement​

warning

Your VRChat account needs to have a trust rank of New User or above in order to be able to upload avatars!
If you just made your VRChat account you will need to play the game or afk in order to increase it from Visitor. Positive interactions with people (such as not getting blocked or getting friend requests) will allow you to gain trust rank faster, alternatively you can pay for VRC+ and gain New User rank immediately!

Trust Ranks

Step 1 - Download the Creator Companion​

The VRChat Creator Companion (usually just called VCC) is a free program made by VRChat. Think of it as a control panel that helps you set up everything else. You install it once and it handles the rest.

  1. Go to vrchat.com and log in with your VRChat account.
  2. Click Downloads from the top menu.
  3. Download the Creator Companion and run the installer like you would any other program.

When you open it for the first time, it will ask you to sign in with your VRChat account. Go ahead and do that.

info

If it asks for a verification code after signing in, check your email - VRChat sends one for security.

Step 2 - Install Unity​

Unity is the program that actually lets you upload the avatar. VCC will prompt you to install it automatically, so you don't need to go hunting for the right version yourself.

  1. Open the Creator Companion.
  2. If Unity isn't installed yet, VCC will show a message asking you to install it. Click Install Unity.
  3. This opens a program called Unity Hub - it's just a launcher that manages Unity for you. Follow the prompts to finish installing.
  4. During setup, you'll be asked to create a free Unity account and activate a Personal license. This is completely free and just lets you use Unity.
warning

Don't install Unity yourself

If you go to the Unity website and download it manually, you'll probably get the wrong version. VRChat is very picky about which version it supports - always let VCC install it for you.

caution

Already have Unity installed? You might have the wrong version.

If you haven't updated VCC or Unity in a while, you may have Unity 2019 installed instead of the required Unity 2022. Using the wrong version will cause your project to break.

To fix this:

  1. First, make sure your Creator Companion itself is up to date - check for updates and install them if available.
  2. Open the Creator Companion and go to Settings in the bottom-left corner.
  3. Click the General tab.
  4. If you see a pop-up or banner that says something like "No Recommended Version Yet" or shows an outdated Unity version, click Install Now.
  5. Wait for Unity Hub to finish installing the correct version.

Once Unity 2022 is installed, you're good to continue.

Step 3 - Create a project​

A "project" is just a folder on your computer where all your avatar files will live. You create and manage it through the Creator Companion.

  1. Open the Creator Companion and click Projects in the sidebar on the left.
  2. Click the blue Create New Project button in the top right.
  3. From the template list, select "Unity 2022 Avatar Project".
  4. Give your project a name and choose where to save it.
tip

Choose a sensible save location

By default, VCC might try to save it inside a hidden system folder (AppData). It's better to save it somewhere easy to find, like Documents\VRChat Projects\ or similar.

  1. Click Create and wait for it to finish. This might take a minute or two.

Step 4 - Add the package sources to VCC​

Before you can install anything, VCC needs to know where to find these packages.

Click Add to VCC on each card below. Once you've clicked all four, a message will appear at the bottom telling you what to do next.

Mandatory Dependencies
VRCFury

Automatically sets up complex avatar features so you don't have to do it manually.

Add to VCC

Didn't work? Go to Settings > Packages > Add Repository and paste:

https://vcc.vrcfury.com
Poiyomi Toon

The shader used for the avatar's materials. Without it, the avatar will appear completely pink.

Add to VCC

Didn't work? Go to Settings > Packages > Add Repository and paste:

https://poiyomi.github.io/vpm/index.json
Optional - but heavily recommended
⚠️ These packages are not strictly required, but pay close attention during the upload process if you skip them - missing packages will produce errors and the upload will fail.
GoGoLoco

Adds movement options like sitting and laying down anywhere in VRChat.

Add to VCC

Didn't work? Go to Settings > Packages > Add Repository and paste:

https://Spokeek.github.io/goloco/index.json
ADJerry's Face Tracking Templates

Adds face tracking support to the avatar.

Add to VCC

Didn't work? Go to Settings > Packages > Add Repository and paste:

https://Adjerry91.github.io/VRCFaceTracking-Templates/index.json
info

You only need to do this once per package, ever. Once a source is added to VCC, it stays there for all future projects too.

Step 5 - Install the packages into your project​

Now that VCC knows where the packages are, you need to actually install them into your project. This is the step that puts them in your Unity project and makes them usable.

  1. Open the Creator Companion and click Projects in the sidebar on the left.
  2. Find your project in the list and click Manage Project.
  3. You'll see a list of packages. Find each of the following and click the button next to them:
  • VRCFury
  • GoGoLoco
  • VRCFT - Jerry's Templates
  • Poiyomi Toon - Make sure you pick Toon, not Pro. Pro is the paid version - if you haven't purchased it, installing Pro will not work correctly.
  1. Wait for VCC to finish installing each one - it may take a moment.
info

You'll know it worked when the version box changes from none to a version number (e.g. 1.2.3), and the button changes to .

Next steps​

Once everything is installed, head to Uploading to get your avatar into VRChat.
