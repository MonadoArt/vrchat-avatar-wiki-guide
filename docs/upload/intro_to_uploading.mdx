# Avatar Wiki

Welcome to the Avatar Wiki — a guide for setting up, uploading, and fixing common problems with avatars.

Use the sidebar to navigate to the section you need.

## What's in this wiki

- **[Upload](./upload)** — How to install your tools and get your avatar into VRChat.
- **[Troubleshooting](./troubleshooting)** — Common errors and how to fix them.

## Before you start

Make sure you have:

- A VRChat account (with [trust rank](https://docs.vrchat.com/docs/vrchat-safety-and-trust-system) of New User or above)
- The [VRChat Creator Companion](https://vcc.docs.vrchat.com/) installed

:::tip
New to this? Start with the [Installation](./upload/installation) page.
:::
