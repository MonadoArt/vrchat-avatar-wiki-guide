## Step 1 - Download the Creator Companion

The <VccIcon />**VRChat Creator Companion** (usually called VCC) is a free program made by VRChat. Think of it as a control panel that helps you set up everything else. You install it once and it handles the rest.

1. Go to [vrchat.com](https://vrchat.com) and log in with your VRChat account.
2. Click **Downloads** from the top menu.
3. Download the <VccIcon />**Creator Companion** and run the installer like you would any other program.

When you open it for the first time, it will ask you to sign in with your VRChat account. Go ahead and do that.

:::info
If it asks for a verification code after signing in, check your email - VRChat sends one for security.
:::

---

## Step 2 - Install Unity

Unity is the program that actually lets you upload the avatar. <abbr title="VRChat Creator Companion">VCC</abbr> will prompt you to install it automatically, so you don't need to go hunting for the right version yourself.

1. Open the <VccIcon />**Creator Companion**.
2. If Unity isn't installed yet, <VccIcon /> VCC will show a message asking you to install it. Click **Install Unity**.
3. This opens a program called **Unity Hub** - it's just a launcher that manages Unity for you. Follow the prompts to finish installing.
4. During setup, you'll be asked to create a free Unity account and activate a **Personal license**. This is completely free and just lets you use Unity.
aaaaaaaaaaaaaa
:::warning
**Don't install Unity yourself**

If you go to the Unity website and download it manually, you'll probably get the wrong version. VRChat is very picky about which version it supports - always let <VccIcon /><abbr title="VRChat Creator Companion">VCC</abbr> install it for you.
:::

:::caution
**Already have Unity installed? You might have the wrong version.**

If you haven't updated VCC or Unity in a while, you may have **Unity 2019** installed instead of the required **Unity 2022**. Using the wrong version will cause your project to break.

To fix this:

1. First, make sure your <VccIcon />**Creator Companion** itself is up to date - check for updates and install them if available.
2. Open the <VccIcon />**Creator Companion** and go to **Settings** in the bottom-left corner.
3. Click the **General** tab.
4. If you see a pop-up or banner that says something like **"Recommended Version Not Installed"**, click **Install Now**.
5. Wait for <VccIcon />Creator Companion to finish installing the correct version.

Once Unity 2022 is installed, you're good to continue.
:::

## Step 3 - Create a project

A <q>project</q> is just a folder on your computer where all your avatar files will live. You create and manage it through the <VccIcon />Creator Companion.

1. Open the <VccIcon />**Creator Companion** and click <VccProjectsLabel /> in the sidebar on the left.
2. Click the blue **Create New Project** button in the top right.
3. From the template list, select **"Unity 2022 Avatar Project"**.
4. Give your project a name and choose where to save it.

:::tip
**Choose a sensible save location**

By default, VCC might try to save it inside a hidden system folder (AppData). It's better to save it somewhere easy to find, like `Documents\VRChat Projects\` or similar.
:::

5. Click **Create** and wait for it to finish. This might take a minute or two.

## Step 4 - Add the package sources to VCC

Before you can install anything, VCC needs to know where to find these packages.

Click <DisabledAddToVccCta /> on each card below. Once you've clicked all four, a message will appear at the bottom telling you what to do next.

<VccPackageCards />

:::info
You only need to do this once per package, *ever*. Once a source is added to VCC, it stays there for all future projects too.
:::

---

## Step 5 - Install the packages into your project

Now that VCC knows where the packages are, you need to actually install them into your project. This is the step that puts them in your Unity project and makes them usable.

1. Open <VccIcon /> **Creator Companion** and click <VccProjectsLabel /> in the sidebar on the left.
2. Find your project in the list and click <VccManageProjectLabel />.
3. You'll see a list of packages. Find each of the following and click the <AddIcon /> button next to them:

<PackageInstallList />
4. Wait for VCC to finish installing each one - it may take a moment.

:::info
You'll know it worked when the version box changes from <VersionNone /> to a version number (e.g. <VersionInstalled />), and the <AddIcon />&nbsp;button changes to <RemoveIcon />.
:::
