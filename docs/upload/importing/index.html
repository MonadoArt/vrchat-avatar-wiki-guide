Importing the Avatar

To get the avatar into Unity you need to import a Unity Package - a .unitypackage file that contains the model, textures, animations, and everything else the avatar needs.

Step 1 - Open your project in Unity​

  1. Open the Creator Companion and go to the Projects tab.
  2. Click Open Project next to your project. Unity will launch, which can take a minute or two.
info

Unity is slow to open. Just let it load.

Step 2 - Get the Unity Package​

You should have a .unitypackage file from your avatar download, named something like Lucario ReUnited VRC.unitypackage.

Step 3 - Import the Unity Package​

There are three ways to do this - pick whichever works for you:

Option A - Right-click the Assets folder​

Option A - Right-click the Assets folder

The Project window is the panel at the bottom of Unity that shows all your project files. Inside it you'll see a folder called Assets in the left sidebar.

warning

Project window vs Hierarchy

These two panels are easy to mix up. The Hierarchy (left side of the screen) shows the objects in your current scene. The Project window (bottom) shows your files on disk. You want the Project window for this step.

  1. Right-click the Assets folder.
  2. Hover over Import Package.
  3. Click Custom Package....
  4. Find your .unitypackage file in the file browser and select it.

Option B - Drag and drop​

Option B - Drag and drop
  1. Open the folder where your .unitypackage file is saved.
  2. Drag the file on top of the Project window in Unity.
  3. Hold until the cursor changes, then let go.

Option C - Double-click the file​

Option C - Double-click the file
  1. Find the .unitypackage file in your file explorer.
  2. Double-click the .unitypackage. If Unity is open it will pick it up automatically.

Double-click Import

Whichever method you used, Unity will show a list of everything in the package. Leave everything checked and click Import.

Wait for the progress bar in the bottom-right corner to finish before doing anything else.

info

FBX import warnings may appear in the Console after importing. As long as the text is yellow and not red, they are safe to ignore.

Step 4 - Find the scene and prefab​

Once the import finishes, navigate to this folder in the Project window:

Assets / Monado_Art / Lucario ReUnited VRC /

You may also notice a _MekenoTools folder in your Assets. It's a dependency that came with the avatar - just leave it alone, you don't need to touch it.

Inside you'll find:

  • The Scene - Double-click to open it. If you're new to Unity this is the easiest starting point since the avatar is already set up inside it.
  • The Prefab - Drag it from the Project window into the Hierarchy to add it to your scene. The included scene has both prefabs placed in it side by side, so opening it first is a good way to see what each one looks like. There are two versions:
    • Lucario ReUnited PC Prefab - the base version, with the Sir Aaron outfit and mohawk hair on by default.
    • Lucario ReUnited PC Lite Prefab - same but with a few things removed to hit a better performance rank. Good pick if you want to be easier on lower-end PCs.

Before you start customizing​

warning

I know, you're probably very excited to start customizing the avatar right now! - but hold off for just a bit! Do a clean upload first to make sure everything is working correctly before you start making changes. It's much easier to spot problems on a fresh import than after you've already modified things.

Head to Uploading to get it into VRChat first.
